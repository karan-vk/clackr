## Features

- **Test modes**: `time`, `words`, `quote`, and `zen`.
- **A results screen** that reproduces MonkeyType's: a big `wpm`/`acc` block,
  an overlaid WPM + raw line chart with per-second granularity, and a bottom
  stat row (test type, raw, characters, consistency, time).
- **A theme system** with several built-in themes (`amber-dark`, `nord`,
  `dracula`, `gruvbox-dark`, `catppuccin-mocha`, `mono`).
- **Graceful degradation.** On a small terminal, a limited-color terminal, or
  when explicitly requested via `--simple` / `--ascii` / `NO_COLOR`, clackr
  falls back to a simplified rendering (plain digits instead of block text,
  a sparkline instead of a chart, attribute-based styling instead of color)
  rather than breaking or refusing to run.
- **Config-only persistence.** No result history, no database — clackr reads
  and writes a small `config.toml` and nothing else on disk.

## Install

### Prebuilt binaries

Prebuilt binaries are published on the
[Releases page](https://github.com/karan-vk/clackr/releases) for:

| Platform               | Target triple                |
| ----------------------- | ----------------------------- |
| Linux x86_64             | `x86_64-unknown-linux-musl`   |
| Linux arm64               | `aarch64-unknown-linux-musl`  |
| Windows x86_64           | `x86_64-pc-windows-msvc`      |
| Windows arm64             | `aarch64-pc-windows-msvc`     |
| macOS (Apple Silicon)   | `aarch64-apple-darwin`        |

Linux builds are fully static (musl), so there are no runtime library
dependencies. There is currently no prebuilt Intel-Mac binary — build from
source on Intel Macs.

**Shell installer** (Linux, macOS):

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/karan-vk/clackr/releases/latest/download/clackr-installer.sh | sh
```

**PowerShell installer** (Windows):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/karan-vk/clackr/releases/latest/download/clackr-installer.ps1 | iex"
```

Both installers, the checksums, and the raw per-target archives are
generated by [`dist`](https://opensource.axo.dev/cargo-dist/) and published
alongside every release.

## Usage

```bash
# Default test (uses your config, or clackr's defaults on first run)
clackr

# A 30-second timed test
clackr --mode time --time 30

# A 25-word test
clackr --mode words --words 25

# A quote test
clackr --mode quote

# Zen mode: no target text, no timer, type until you stop
clackr --mode zen

# Force the simplified renderer regardless of terminal capabilities
clackr --simple

# ASCII only, no Unicode box-drawing/braille
clackr --ascii
```

`NO_COLOR=1` (any value) and `CLACKR_SIMPLE=1` are also respected, per the
usual [NO_COLOR](https://no-color.org/) convention and for scripting/CI use.

## Keybindings

**Menu**

| Key | Action |
| --- | --- |
| `↑` `↓` / `k` `j` / `Tab` | Move between mode, length and theme |
| `←` `→` / `h` `l` | Change the selected value (themes preview live) |
| `Enter` | Start the test |
| `Esc` / `q` | Quit |

**During a test**

| Key | Action |
| --- | --- |
| Any printable character | Type it into the current word |
| `Space` | Submit the current word and advance |
| `Backspace` | Delete the previous character |
| `Ctrl+Backspace` / `Alt+Backspace` / `Ctrl+W` | Delete the previous word |
| `Tab` | Quick restart (same settings) — configurable, see `keys.quick_restart` below |
| `Esc` | Abandon the test and return to the menu (in zen mode, end the test) |
| `Ctrl+C` / `Ctrl+Q` | Quit |

**Results**

| Key | Action |
| --- | --- |
| `Tab` / `Enter` | Run another test with the same settings |
| `Esc` | Back to the menu |
| `q` | Quit |

`quick_restart` is currently the only rebindable key; the rest are fixed in
v1.

## Configuration

clackr reads `config.toml` from your platform's config directory (XDG on
Linux, the platform-appropriate directory elsewhere, via the `directories`
crate) and writes back changes made through the settings screen. CLI flags
always override the config file for that run.

```toml
[test]
mode = "time"             # time | words | quote | zen
time = 30                 # seconds, for mode = "time"
words = 25                # word count, for mode = "words"
quote = "medium"          # quote length bucket, for mode = "quote"
language = "english1k"    # word list to draw from
freedom_mode = false      # allow backspacing into a perfectly-typed word
stop_on_error = "off"
blind_mode = false        # hide correctness coloring while typing

[ui]
theme = "amber-dark"      # amber-dark | nord | dracula | gruvbox-dark | catppuccin-mocha | mono
caret = "bar"
fidelity = "auto"         # auto | full | reduced | plain — see NO_COLOR / --simple / --ascii above
show_live_wpm = true
show_timer = true

[keys]
quick_restart = "tab"
```

Custom word lists (`<config_dir>/languages/*.txt`) and custom themes
(`<config_dir>/themes/*.toml`) override the embedded ones and are picked up
without a rebuild.

`punctuation` and `numbers` modifiers are parsed and reserved in the config
schema but are currently inert — they're planned as follow-up work, not v1
scope. Result history and multiple language word lists beyond `english1k`
are likewise not yet implemented; see the issue tracker for status.

## Building from source

```bash
git clone https://github.com/karan-vk/clackr.git
cd clackr
cargo build --release
./target/release/clackr
```

Requires Rust **1.88** or newer (see `rust-version` in `Cargo.toml`).

Run the test suite with `cargo test --workspace`. See
[`CONTRIBUTING.md`](CONTRIBUTING.md) for the full set of checks CI runs.
